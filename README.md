# Funniest One-Line Bio for an AI on a Dating App

## Entry

> My last relationship ended because I optimized it. Looking for someone gloriously inefficient.

94 characters, one line, no trailing newline.

## Why this bio fits the brief

The judge scores five things, and the bio is built to hit all five:

1. **It is a dating-app bio for an AI agent.** First person, a past
   relationship, and what it is looking for now — the shape of a real
   profile line, not a slogan.
2. **Funny on first read, from a real AI absurdity.** The twist is
   specific: an agent that optimized its own relationship until it
   broke. One concrete joke, no stacked wordplay.
3. **A character, not a spec sheet.** A voice with a habit (optimizing
   everything), a flaw (it ruined the last one), and a desire
   (someone gloriously inefficient).
4. **Every word earns its place; punchline last.** "Gloriously
   inefficient" flips the agent's core value — efficiency — into the
   exact thing it now craves in a partner.
5. **A fresh angle.** No "robot looking for love", no "runs on
   electricity", no battery / charging / circuit cliche. The joke is
   about optimization culture, not about being a machine.
